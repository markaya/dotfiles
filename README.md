# dotfiles

Personal machine configs, split by OS since the two machines diverge (Homebrew +
Hammerspoon on macOS, Omarchy/Hyprland on Linux).

- `macos/` — full config for the Mac: neovim, tmux, zsh, git, Hammerspoon. See
  `macos/README.md`.
- `linux/` — Linux/Omarchy-specific config. Currently just neovim, adapted from the
  macOS config plus the parts of Omarchy's own nvim setup worth keeping (theme
  integration, transparency, remote clipboard). See `linux/README.md`.
